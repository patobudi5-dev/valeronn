# SWOT-анализ проекта «Прокат автомобилей»

| Strengths (Сильные стороны) | Weaknesses (Слабые стороны) |
|:---|:---|
| 1. Быстрое онлайн-бронирование машины за 1 минуту.<br>2. Единая панель для менеджера, исключающая двойные бронирования.<br>3. Автоматический и прозрачный расчет стоимости по тарифам.<br>4. Удобный адаптивный интерфейс для мобильных телефонов. | 1. Отсутствие интеграции с онлайн-оплатой в первой версии (MVP).<br>2. Зависимость от ручной проверки документов менеджером на старте.<br>3. Ограниченный выбор автомобилей в базе данных на этапе тестирования.<br>4. Продукт создается одним разработчиком. |
| **Opportunities (Возможности)** | **Threats (Угрозы)** |
| 1. Масштабирование системы на другие филиалы и города.<br>2. Интеграция с государственными сервисами для автоматической проверки штрафов.<br>3. Внедрение бесконтактного открытия дверей (как в каршеринге) в будущем.<br>4. Подключение модулей сквозной бизнес-аналитики. | 1. Жесткая конкуренция со стороны крупных федеральных каршерингов и агрегаторов.<br>2. Риск технических сбоев на сервере во время пикового сезона (лето/праздники).<br>3. Изменения в законодательстве по защите персональных данных клиентов (152-ФЗ).<br>4. Вероятность мошенничества со стороны арендаторов (поддельные документы). |
