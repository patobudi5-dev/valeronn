# Глоссарий предметной области «Прокат автомобилей»

| Термин | Определение |
| :--- | :--- |
| **Бронирование** | Оформленный запрос клиента на аренду автомобиля на определенные даты и время. |
| **Арендатор (Клиент)** | Физическое или юридическое лицо, пользующееся услугой проката транспортного средства. |
| **Автомобиль** | Основной объект проката, имеющий уникальные характеристики (марка, модель, госномер, год выпуска). |
| **Класс автомобиля** | Категория машины по уровню комфорта и стоимости (например: Эконом, Комфорт, Бизнес, Кроссовер). |
| **Тариф** | Фиксированная стоимость аренды транспортного средства за единицу времени (обычно за сутки). |
| **Залог (Депозит)** | Обеспечительный платеж, который временно блокируется на время аренды для покрытия возможных штрафов или повреждений. |
| **Статус автомобиля** | Текущее состояние машины в системе (например: Доступен, В прокате, На ТО, В ремонте). |
| **Статус бронирования**| Этап обработки заказа (например: На рассмотрении, Подтвержден, Активен, Завершен, Отменен). |
| **Менеджер** | Сотрудник компании, проверяющий документы клиента и оформляющий выдачу или прием автомобиля. |
| **Договор аренды** | Официальный документ, закрепляющий права, обязанности и ответственность сторон на период проката. |
| **Пункт выдачи** | Физический адрес (офис или стоянка), где происходит передача ключей и автомобиля клиенту. |
| **Доп. оборудование** | Вспомогательные опции, предоставляемые за отдельную плату (детское кресло, навигатор, крепление для лыж). |
