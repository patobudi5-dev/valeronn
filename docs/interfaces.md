# Проектирование интерфейсов системы «Прокат автомобилей»

## 1. Карта страниц (Архитектура ИР)
Информационный ресурс делится на три основные зоны:
1. **Публичная часть (Гость):** Главная страница, Каталог авто, Условия аренды, Контакты.
2. **Личный кабинет (Клиент):** Профиль, Мои документы, История бронирования, Активный заказ.
3. **Панель управления (Менеджер):** Сводная панель, Управление автопарком, Список заказов, База клиентов.

## 2. Текстовые макеты ключевых экранов (Wireframes)

### Экран 1: Каталог автомобилей (Вид для Клиента)

```text
+-----------------------------------------------------------------------+

|  [ Лого: АвтоПрокат ]   Главная   Каталог   Условия   [ Личный Кабинет ] |
+-----------------------------------------------------------------------+

| Фильтры: Класс авто: [ Все v ]   Цена до: [ 10000 руб ]  [ Применить ] |
+-----------------------------------------------------------------------+

|                                                                       |
|  +-----------------------+   +-----------------------+                |
|  | Фото Hyundai Solaris  |   | Фото Toyota Camry     |                |
|  | Класс: Эконом         |   | Класс: Комфорт        |                |
|  | Тариф: 2500 руб/сутки |   | Тариф: 5000 руб/сутки |                |
|  | Статус: Доступен      |   | Статус: В прокате     |                |
|  |                       |   |                       |                |
|  | [ Забронировать ]     |   | [ Занята до 18.10 ]   |                |
|  +-----------------------+   +-----------------------+                |
|                                                                       |
+-----------------------------------------------------------------------+
```
